ExamFlow complete project
=========================
database/      MySQL schema, stored procedures, demo accounts and verification queries
backend/       Express REST API and MySQL connection
frontend/      React UI, login/registration, admin, student and teacher portals
setup_windows.bat       Installs npm packages and creates backend/.env from template
start_all_windows.bat   Starts API and web frontend in separate terminal windows
